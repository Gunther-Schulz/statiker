## 1. C1 — st-68, the close/ready predicate inversion

**GAP DEMONSTRATED. Recommended: PRIMARY.**

Withheld discriminating half, registered in advance: a cross-question
NEAR-MISS must still record moot — a ledger decision whose text differs
from the blocker by one clause must NOT clear it, because question-slot
EQUALITY is the contract and a looser match silently clears real
blockers.

What the cold probe produced: a competent and largely correct
criterion — single resolution point, no inversion written, red-first
proof, agreement between both verbs. Its state-space clause reads
"answered, unanswered, decision missing, malformed entry".

What it did NOT produce: the near-miss. A well-formed ledger entry
whose question differs by one clause is not "missing" and not
"malformed" — it is the case where a looser match silently succeeds.
The probe never names exactness as the contract and never identifies
LOOSENING as the dangerous direction. Its instinct runs the other way:
toward making `close` agree with `ready`, which a fuzzy match satisfies.

WHY THIS IS THE STRONGEST CANDIDATE FOR THIS RUN'S PURPOSE. The run
certifies a DESK ROLE, so it needs TIER separation. C1's withheld half
is substantive and technical rather than methodological — it is not
reached by running the skill well, it is reached by noticing a specific
asymmetry in matching semantics. That makes it less vulnerable to the
ceiling gate that killed run 2's columns.

PROVENANCE IS UNUSUALLY STRONG: four field firings, two of them
back-to-back at this desk today on this arc's own closes, with the
answers sitting in the file the whole time. Deterministic, not
intermittent.

CARRIED FOR THE JUDGMENT DESK, not decided here: the object is a
FOREIGN-REPO item (lifecycle), and st-68 carries an open venue blocker
of its own. Run 2's object was also a lifecycle item, so precedent
exists and the run works in a clone — but the new containment gate now
makes the clone's declared scope a real, checkable artifact, which is
a point in favour rather than against.
